# MOSS 语音助手 —— 接线方案与端口定义

> 本文件对应已购硬件清单，给出 ESP32-C3（默认 ESP32-C3-DevKitM-1）的接线方式与 GPIO 端口映射。
> 所有 GPIO 均需**以实际开发板丝印/原理图为准**，接线前用万用表/导通表核对一遍。
>
> 📷 完整接线示意图（按实购硬件绘制，含信号颜色图例与注意事项）见同目录 [`接线图-ESP32C3-MOSS.png`](接线图-ESP32C3-MOSS.png)。

---

## 1. 已购硬件与其角色

| 序号 | 硬件 | 已购型号/规格 | 在系统中的作用 |
|---|---|---|---|
| 1 | I2S 麦克风 | INMP441 全向麦克风模块（MEM） | 采集语音 PCM |
| 2 | I2S 功放 | MAX98357 I2S 音频放大器模块（已焊排针） | 驱动扬声器播放 TTS |
| 3 | 扬声器 | 小喇叭 5W 3寸 全频 | 播报 MOSS 回复 |
| 4 | 状态灯 | 16 位 WS2812 5050 RGB 灯环 | 待机/录音/联网/报警状态指示 |
| 5 | 按钮 | 轻触开关（10 种常用直插微动开关包） | 按下开始录音 |
| 6 | 主控 | ESP32-C3（假设 DevKitM-1） | 采音、上传、播放、状态控制 |
| 7 | 电源 | USB 移动电源 / 5V 2A 适配器 | 整机供电（先不做锂电池） |

> 注意：扬声器是 5W 3寸全频，MAX98357A 为**单声道（BTL）输出**，只能输出一左一右两线直接接喇叭（无需接 GND 参考）。

## 2. GPIO 端口分配总表（ESP32-C3）

> 设计原则：**避免占用启动/下载相关的引脚**（GPIO0=BOOT 下载口、GPIO2=strapping、GPIO18/19=USB），并优先让 BCLK/WS 在录音与播放时复用（ESP32-C3 只有 1 个 I2S0，需在 RX 和 TX 间切换）。

| 信号 | GPIO | 方向 | 连接对象 | 备注 |
|---|---|---:|---|---|
| I2S BCLK | **GPIO4** | OUT | 麦克风 SCK **和** 功放 BCLK 共用 | 同一根线分叉到两器件 |
| I2S WS / LRCLK | **GPIO5** | OUT | 麦克风 WS **和** 功放 LRC 共用 | 同一根线分叉到两器件 |
| I2S 麦克风数据 | **GPIO6** | IN | INMP441 SD → 进 ESP32 | 录音模式的数据输入 |
| I2S 功放数据 | **GPIO7** | OUT | ESP32 → MAX98357A DIN | 播放模式的数据输出 |
| 录音按钮 | **GPIO1** | IN | 轻触开关一端接 GPIO1，另一端接 GND | 内部上拉，按下为 LOW |
| WS2812 灯环数据 | **GPIO10** | OUT | WS2812 灯环 DIN | 点亮灯环 |
| （备用）舵机 PWM | GPIO3 | OUT | 后续可接 SG90 头部转向 | 本轮可不接 |
| （备用）OLED | 预留 | — | 后续可选 SSD1306 | 本轮不做 |

**暂不使用的引脚**：GPIO0 / GPIO2 / GPIO8 / GPIO9 / GPIO18 / GPIO19 —— 其中 GPIO0 是 BOOT，GPIO9 常为板上 BOOT/用户 LED，GPIO18/19 是 USB，避免冲突。

> 相对原方案 `接线方案与端口定义`，本次仅调整了两处：录音按钮改为 **GPIO1**（避免和 GPIO9 板上 BOOT 键冲突）、状态灯改为 **GPIO10**（避免占用 GPIO8 板上用户 LED）。

## 3. 各器件接线明细

### 3.1 INMP441 麦克风模块

| 麦克风引脚 | 接到 |
|---|---|
| VDD | 3.3V |
| GND | GND（与 ESP32 共地） |
| SCK（BCLK） | ESP32 **GPIO4**（与功放 BCLK 共用） |
| WS（LRCLK） | ESP32 **GPIO5**（与功放 LRC 共用） |
| SD（DOUT） | ESP32 **GPIO6** |
| L/R（声道选择） | **GND**（选左声道，对应左对齐 I2S） |

### 3.2 MAX98357A 功放模块

| 功放引脚 | 接到 |
|---|---|
| VIN | **5V**（USB 5V / VBUS） |
| GND | GND（与 ESP32 共地） |
| DLIN / DIN | ESP32 **GPIO7** |
| BCLK | ESP32 **GPIO4**（与麦克风共用） |
| LRC | ESP32 **GPIO5**（与麦克风共用） |
| SD（静音/使能） | **VIN**（拉高使能；如想用 GPIO 控制静音可接空闲 GPIO） |
| GAIN | 悬空或接 GND（默认增益；低音量可用） |
| 输出 - / + | 直接接扬声器两根线（单声道 BTL，不用接 GND） |

### 3.3 扬声器（5W 3寸全频）

- 喇叭两根引线分别接 MAX98357A 的 **+ / -** 输出端子。
- 单声道 BTL 输出，**不需要**公共地参考，两根线直连即可。
- 喇叭不要紧贴麦克风，外壳打 1~2mm 网孔并保持一定距离，避免啸叫。

### 3.4 WS2812 5050 RGB 灯环（16 位）

| 灯环引脚 | 接到 |
|---|---|
| 5V（VDD） | **5V**（与功放同电源，注意电流）|
| GND | GND（共地） |
| DIN | ESP32 **GPIO10** |
| DOUT | 不接（单灯环；如多灯环串联则接下一环 DIN） |

### 3.5 轻触开关

- 轻触开关是 4 脚（对角两组内部相连）。用一组对角脚：一脚接 **GPIO1**，另一脚接 **GND**。
- 固件用 `INPUT_PULLUP`，按下时 GPIO1 被拉低触发录音。

## 4. 供电与共地

| 电源轨 | 供电对象 | 说明 |
|---|---|---|
| 3.3V | INMP441 VDD、ESP32 逻辑 | 由开发板稳压器提供，电流很小 |
| 5V（VBUS/VIN） | MAX98357A VIN、WS2812 5V | 直接从开发板 5V 口取电；电流较大，建议 USB 5V 2A |
| GND | 所有模块 | **必须全部共地**，否则 I2S 数据会异常 |

关键提醒：

1. **所有器件必须共地**。功放/麦克风/灯环与 ESP32 的 GND 连在一起。
2. **电源线尽量独立走线**，不要从 ESP32 的 3.3V 引脚给功放/灯环取电（电流会超）。
3. 灯环满亮度 16 珠电流可能到 ~0.5~1A，功放 5W 也会拉电流，**整机建议 5V 2A 供电**；演示时控制灯环亮度即可避免供电不足。
4. 如果 MAX98357A 或 WS2812 在 5V 供电下对 3.3V 数据不敏感（逻辑高阈值约 0.7×VDD≈3.5V，略高于 3.3V），实际多数能正常工作；若**信号不稳导致无声/不亮，可把 VIN/5V 改接到 3.3V**（音量/亮度略降但信号可靠）。

## 5. 固件引脚定义（与 Arduino 模板对应）

```cpp
// I2S —— 麦克风 INMP441 + 功放 MAX98357A 共用 I2S0，录音/播放切换
#define PIN_BCLK      4   // GPIO4  → 麦克风 SCK 与功放 BCLK 共用
#define PIN_LRCLK     5   // GPIO5  → 麦克风 WS  与功放 LRC  共用
#define PIN_MIC_DIN   6   // GPIO6  ← INMP441 SD（数据输入）
#define PIN_SPK_DOUT  7   // GPIO7  → MAX98357A DIN（数据输出）

// 其他外设
#define PIN_LED_RING  10  // GPIO10 → WS2812 灯环 DIN
#define PIN_BUTTON    1   // GPIO1  → 轻触开关（内部上拉，按下 LOW）

// 声道/采样参数（与接线一致：麦克风 L/R 接地=左声道）
#define SAMPLE_RATE    16000
#define RECORD_SECONDS 4
#define I2S_CHANNEL_FMT I2S_CHANNEL_FMT_ONLY_LEFT  // 录音
#define I2S_TX_CHANNEL_FMT I2S_CHANNEL_FMT_RIGHT_LEFT // 播放
```

若只需复用原方案固件，把原模板里：

```cpp
#define PIN_LED    8
#define PIN_BUTTON 9
```

替换为：

```cpp
#define PIN_LED    10   // WS2812 数据（灯环）；若用普通 LED 可另接
#define PIN_BUTTON 1
```

> 注意：原模板中 WS2812 灯环需要用驱动库（如 `Adafruit NeoPixel`），普通 `digitalWrite` 只适用于普通单色 LED。若暂不接灯环、只用单色 LED 做状态灯，可把 `PIN_LED` 单独接到一个 GPIO 并保持 `digitalWrite` 用法。

## 6. 接线顺序建议（减少返工）

1. 先只接**电源和地**，确认 3.3V/5V/GND 正常。
2. 接**WS2812 灯环**（GPIO10），点亮测试。
3. 接**轻触开关**（GPIO1），串口打印确认按下/松开。
4. 接 **MAX98357A + 扬声器**（GPIO7/4/5），播放一段 WAV 或 TTS 测试。
5. 接 **INMP441**（GPIO6/4/5），串口打印采集到的 PCM 是否非零。
6. 最后联调：按键录音 → 上传 → 识别 → 播放。

## 7. 首次上电自检清单

- [ ] 3.3V / 5V / GND 三线均正确，无短路（上电前先用万用表测通断）。
- [ ] WS2812 通电后能点亮/可被驱动。
- [ ] GPIO1 按下时串口能读到 LOW。
- [ ] MAX98357A 能否播放声音（SD 是否拉高使能）。
- [ ] INMP441 采集到的 PCM 有波动（不是一直为 0）。
- [ ] 所有模块共地，无明显发热。
- [ ] 喇叭与麦克风保持距离，无啸叫。

> 常见坑：功放 SD 悬空导致静音；麦克风/功放未共地导致采集全零或杂音；WS2812 数据线接反（DIN/DOUT 接反会不亮）；5V 供电不足导致灯环闪烁或功放失真。
